# Merge (Unified API + Agent Handler)

## Observation (checked 2026-10-23)

- **What it is:**
  - The core product is a unified API: one normalised schema per category (HR, ATS, CRM, accounting, ticketing, files), delivered by syncing data.
  - Agent Handler is the part that overlaps with viaSocket. It provides MCP connectors with per-user tool access, DLP, audit logs and SCIM ([agent handler](https://www.merge.dev/agent-handler)).
- **Positioning:** "The universal context engine for agents" ([merge.dev](https://www.merge.dev/))
- **Auth:** Merge Link, a drop-in component, and Magic Link ([docs](https://docs.merge.dev/merge-unified/merge-link/)).
- **Integrations claimed (conflicting):**
  - Homepage: "5,000+ tools".
  - Agent Handler page: "thousands" in the headline and "hundreds of enterprise systems" in its FAQ.
  - Integrations page: "Hundreds of integrations".
- **Pricing** (2026-10-23, volatile):
  - Unified API ([pricing](https://www.merge.dev/pricing)): free for 3 linked accounts; Launch $650/mo for 10, then $65 per account.
  - Agent Handler ([pricing](https://www.merge.dev/pricing/agent-handler)): Free with 2,000 credits; Pro $1,000/mo.
- **Proof:**
  - Logos: OpenAI, Perplexity, Dropbox, Ramp.
  - Badges: SOC 2 Type II, ISO 27001, HIPAA, GDPR.

## Interpretation

- Merge is a different model from viaSocket: normalised data rather than per-app actions and triggers.
- It has the strongest brand and compliance in the unified-API substitute category.
- Agent Handler targets the same agent buyers as viaSocket.

## Recommendation (Proposed)

- Treat Merge as the reference for "unified API" in substitutes copy. Do not compare features directly without approval.
- **Watch:** https://www.merge.dev/pricing, https://www.merge.dev/pricing/agent-handler, https://www.merge.dev/changelog
