# Tray Embedded (Tray.ai)

## Observation (checked 2026-10-23)

- **Positioning:** "Embedded integration, built once and run for every customer." ([embedded](https://tray.ai/embedded))
- **Embedded features:**
  - white-label setup screens, sign-in on your own subdomain and your own OAuth app
  - each customer connects their own accounts
  - monitoring of failed runs
- **Agents and MCP:** embedded MCP or agents were not found on the embedded page. The main platform has an agent builder and an MCP gateway ([tray.ai](https://tray.ai/)).
- **Integrations claimed:** "700+ connectors" (homepage, pricing).
- **Pricing** ([pricing](https://tray.ai/pricing), 2026-10-23, volatile):
  - Usage-based, with "no per-user, per-connection" fees.
  - "Starts at $50 a month", but all tiers are "Talk to sales".
  - 30-day trial.
- **Proof:**
  - Logos: Cisco, Airbnb, Notion, DocuSign.
  - Embedded case studies: Podium, HackerOne, Cvent.
  - Badges: SOC 1 & 2, HIPAA, GDPR.

## Interpretation

- Tray is an enterprise platform, and embedded is a use case within it rather than its own product.
- Its overlap with viaSocket's ICP is low.

## Recommendation (Proposed)

- Monitor quarterly.
- **Watch:** https://tray.ai/pricing, https://tray.ai/embedded
