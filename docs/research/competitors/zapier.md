# Zapier (MCP, Embedded MCP, Powered by Zapier)

## Observation (checked 2026-10-23)

- **Positioning:** "Power your product or AI agent with 9,000 app integrations" ([developer platform](https://zapier.com/developer-platform)). This overlaps closely with viaSocket's repositioned line.
- **Products relevant here:**
  - Zapier MCP mainly serves end users and IT connecting AI clients.
  - Embedded MCP gives each end user their own MCP server URL, called with an embed secret ([embed MCP docs](https://docs.zapier.com/mcp/embed/getting-started)).
  - Powered by Zapier offers a Workflow API and quick account creation, which makes a Zapier account for the user in the background. It requires your app to be listed in Zapier's App Directory ([docs](https://docs.zapier.com/powered-by-zapier/introduction)).
  - AI Actions is reported as deprecated in favour of MCP. Seen in search results and a community reply only; not confirmed from an official notice.
- **Integrations claimed:** "9,000+ apps" with "30,000+ actions" and also "66,000+ triggers and actions" ([mcp](https://zapier.com/mcp)). "Thousands of apps" on [partner/embed](https://zapier.com/partner/embed).
- **Pricing** ([pricing](https://zapier.com/pricing), 2026-10-23, volatile):
  - Free: 100 tasks.
  - Pro: from $19.99/mo billed annually.
  - Each MCP tool call costs 2 tasks.
  - Embedded and partner pricing is not public (form only).
- **Proof:**
  - Logos on the MCP page: Nvidia, Meta, Cursor, Okta, Shopify.
  - SOC 2 Type II.

## Interpretation

- Zapier is the strongest brand in the category and directly contests viaSocket's message.
- Its embedded routes depend on Zapier accounts and a Zapier directory listing. That is a factual contrast with viaSocket, which is per-user and fully branded.
- On raw breadth (9,000+ apps) Zapier is ahead, so viaSocket cannot win a count comparison.

## Uncertainties

- Whether embedded MCP users need their own Zapier accounts, and whose tasks they consume.
