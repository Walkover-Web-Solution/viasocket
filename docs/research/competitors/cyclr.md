# Cyclr

## Observation (checked 2026-10-23)

- **Overlap:** embedded iPaaS for SaaS companies, in Native, Service and Branded (white-label) variants. It has an embedded marketplace where end users authenticate and install integrations. It also sells an MCP PaaS that turns a SaaS company's own API into MCP servers.
- **Positioning:** "One platform for embedded integration, AI interoperability and data governance." ([cyclr.com](https://cyclr.com/))
- **Capabilities:**
  - an embedded marketplace and a headless option
  - a custom-connector toolkit
  - private cloud in AWS or Azure
  - MCP PaaS with OAuth 2.1. Per-customer self-service is marked "Coming soon" ([MCP PaaS](https://cyclr.com/product/mcp-paas)).
- **Integrations claimed:** "600+ Connectors" (homepage and MCP PaaS page, 2026-10-23).
- **Pricing** ([pricing](https://cyclr.com/pricing), 2026-10-23, volatile):
  - Native Embedded: from $1,595/mo.
  - Service Embedded: from $1,495/mo.
  - MCP PaaS: from $999/mo, plus a $5,000 onboarding fee.
  - Extra connectors: $100 per connector per month.
  - The page does not clearly map every figure to a plan.
  - No free tier; a trial or proof of concept is offered.
- **Onboarding:** sales-led trial or proof of concept, with solutions-architect support.
- **Proof:**
  - Logos: Verint, Medallia, Simpplr, Pod Point, Force24.
  - Badges: SOC 2 Type II, GDPR ([security](https://cyclr.com/security-and-compliance)).

## Interpretation

- Cyclr gives a public price anchor for embedded iPaaS (over $1k a month) that viaSocket's self-serve pricing sits far below.
- Its push to host MCP servers for a SaaS company's own API is a different job from viaSocket's.

## Uncertainties

- Which price belongs to which plan.
