# Make

## Observation (checked 2026-10-23)

- **Audience:** internal teams automating their own work. The homepage says nothing about embedding.
- **Positioning:** "Build and manage AI agents and automations in one visual landscape" ([make.com](https://www.make.com/en))
- **MCP:** the MCP server exposes the account owner's own scenarios as tools for ChatGPT, Claude or Cursor, on all plans ([mcp](https://www.make.com/en/mcp)). It does not give a product's end users their own connections.
- **White label:** an OEM white-label instance exists, but only in the developer docs ([white-label docs](https://developers.make.com/white-label-documentation)). Its pricing is not public. make.com/en/white-label returned 404.
- **Integrations claimed:** "3,500+ apps" and "3,000+ native apps", both on the same pages.
- **Pricing** ([pricing](https://www.make.com/en/pricing)):
  - Free: 1,000 credits a month.
  - Paid prices did not render when fetched, so they are not verified here.
- **Proof:**
  - "500,000+ teams".
  - Badges: SOC 2 Type II, SOC 3, GDPR.

## Interpretation

- Make is a substitute rather than a competitor. A builder's end users may use Make themselves instead of the builder offering native integrations.
- Make's OEM instance is a possible indirect threat, but it has a low public profile.

## Recommendation (Proposed)

- Monitor quarterly.
- **Watch:** https://www.make.com/en/pricing, https://www.make.com/en/mcp, https://developers.make.com/white-label-documentation
