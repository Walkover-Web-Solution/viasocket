# Albato Embedded

## Observation (checked 2026-10-23)

- **Overlap:** SaaS companies offering native integrations that end users switch on inside the product. It now also pitches embeddable AI agents and an MCP server ([albato.com](https://albato.com/)).
- **Positioning:** "Embed AI Agents connected to 1,000+ apps" ([albato.com](https://albato.com/))
- **Core promise:** white-label, AI-powered integrations inside your SaaS within weeks, sold on retention and revenue.
- **Capabilities** ([embedded](https://albato.com/embedded)):
  - embedding by iFrame or API, plus MCP and a "Universal MCP" that exposes the whole catalog
  - a gray-label auth app, with white-label OAuth on Pro and above
  - end users created automatically
  - polling triggers
  - "App Integrator" for building custom connectors
  - health monitoring and alerts
  - self-hosting on Enterprise
  - agent action logs kept for 60 days ([ai-rollups](https://albato.com/embedded/ai-rollups))
- **Stated limitations:**
  - Only apps with an accessible API can be integrated.
  - White-labeling needs each provider to approve an auth app.
  - Typical rollout takes 4 to 8 weeks.
  - ISO 27001 is still in progress ([security](https://albato.com/embedded/security)).
- **Integrations claimed:** "1,000+ ready-to-use integrations and AI apps" ([embedded](https://albato.com/embedded), 2026-10-23).
- **Pricing** ([pricing](https://albato.com/embedded/pricing), 2026-10-23, volatile):
  - Starter: from $3,000/mo, with no white label.
  - Pro: from $5,000/mo, with full white label.
  - Enterprise: custom.
  - No free tier; a 2 to 4 week proof of concept is offered.
  - Transaction caps conflict across the page (5M, 10M and "unlimited" all appear).
- **Onboarding:** sales-led in five stages, with a dedicated team and about two months to launch.
- **Proof:**
  - Logos: Bitrix24, Duda, Chatfuel, RD Station, Knack.
  - Badges: SOC 2 Type 2, GDPR.
  - Stats: "20,000+ active embedded users" and "1B+ API calls a month".

## Interpretation

- Albato is the same pitch as viaSocket, aimed at mid-market SaaS through sales.
- viaSocket's contrasts are self-serve onboarding, a free tier, and a larger stated catalog.
- Albato's case studies show proof that viaSocket's homepage does not have.

## Uncertainties

- Whether the MCP server can be used without a contract.
- No public developer docs or changelog were found.
